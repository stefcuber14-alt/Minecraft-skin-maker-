Скачать APK

Файл для Android. Версия 1.1 и новее.

Как установить

  1. Нажмите «Скачать APK» и откройте файл из загрузок.
  2. Если Android спросит про установку из неизвестных источников, разрешите её для браузера.
  3. Если Chrome предупреждает, что файл небезопасен, выберите «Всё равно скачать». Это обычное предупреждение для приложений вне Google Play.
  4. Для обновления просто установите новый APK поверх старого.
